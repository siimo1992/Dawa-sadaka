# إصلاح منظومة تحميل تطبيق الأندرويد (APK) وإدارة الإصدارات — تيديكلت AI

حل مشكلة عدم اكتمال تنزيل ملف `APK` أو ظهور خطأ تحليل الحزمة عند التحميل عبر ربط زر التحميل برابط خارجي مباشر أو ملف `APK` مرفوع فعلياً من لوحة تحكم المالك، مع استثناء مسارات التحميل من التخزين المؤقت للـ Service Worker وتوفير تثبيت PWA المباشر كخيار مساند.

## User Review & Critical Decisions

> [!IMPORTANT]
> القرارات المعتمدة بناءً على اختيارك:
> - **Confirmed Decision 1 (ربط التحميل المباشر)**: ربط زر تنزيل الأندرويد برابط خارجي مباشر خاص بك (مثل Google Drive المباشر أو GitHub Releases أو MediaFire/Direct URL) أو ملف `APK` مرفوع على الخادم، مع ضبط ترويسات `Content-Type: application/vnd.android.package-archive` و `Content-Disposition` لضمان تنزيل الحزمة كاملة دون تلف.
> - **Confirmed Decision 2 (أداة إدارة APK في لوحة المشرف)**: إضافة قسم مخصص للمالك (داخل نافذة التحميل ولوحة المشرف) يتيح تحديث رابط الـ APK الخارجي، أو رفع ملف `.apk` الفعلي مباشرة، مع تحديد رقم الإصدار وحجم الملف وملاحظات التحديث.

---

## 1. Overview & Core Concept

- **What It Does**:
  1. **معالجة جذرية لسبب تلف/انقطاع التحميل**: كان الملف السابق مجرد ملف نصي تجريبي بحجم 41 بايت كما أن الـ Service Worker كان يعترض طلبات `/downloads/` ويعيد استجابات مخزنة مؤقتاً غير مكتملة. سيتم استثناء مسارات التحميل من الـ Service Worker وتوجيه التحميل عبر مسار خادم مخصص أو الرابط الخارجي المباشر المعتمد من المالك.
  2. **إدارة كاملة للمالك (Owner APK Manager)**: عندما يكون المالك مسجلاً للدخول (أو يفتح إعدادات المالك في نافذة التحميل)، يمكنه:
     - إدخال وتحديث **رابط تحميل خارجي مباشر (Direct APK URL)** مثل روابط GitHub Releases أو Google Drive المباشرة (مع تحويل تلقائي لروابط مشاركة Google Drive إلى روابط تنزيل مباشر).
     - أو **رفع ملف `.apk` حقيقي** من جهازه ليُحفظ على الخادم ويُقدَّم بترويسات binary قياسية كاملة مع دعم استئناف التحميل (`Accept-Ranges: bytes`).
     - تعديل رقم الإصدار (مثل `v2.4.0`) وحجم الحزمة وتاريخ التحديث.
  3. **تجربة تحميل موثوقة للمستخدم**: تعرض نافذة التحميل معلومات الإصدار الفعلي، حجم الملف، شريط تقدم التحميل المباشر، وخيار التثبيت الفوري كتطبيق ويب (PWA) بضغطة واحدة في حال رغب المستخدم بالتثبيت السريع دون انتظار تنزيل الحزمة.
- **Target Audience / Persona**: زوار ومستخدمو منصة **تيديكلت AI** على هواتف أندرويد وآيفون، ومالك المنصة المشرف على نشر التحديثات.
- **Key Value**: تنزيل سليم ومكتمل 100% لملف الـ APK دون أخطاء "فشل التحميل" أو "حدثت مشكلة أثناء تحليل الحزمة"، مع مرونة كاملة للمالك في تحديث الرابط أو الملف في أي وقت دون تعديل الكود.

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **تدفق الزائر لتحميل التطبيق**:
     - يضغط المستخدم على زر **"تحميل التطبيق"** في الشريط العلوي أو القائمة الجانبية.
     - تفتح نافذة **"تنزيل تطبيق تيديكلت AI"** بتصميم متناسق مع هوية التطبيق (`--green: #176b52`، `--bg`، `--card`) وتعرض:
       - بطاقة إصدار الأندرويد (`APK`) شاملة رقم الإصدار، حجم الملف، وحالة الرابط الموثق.
       - زر رئيسي واضح **"تنزيل APK لأندرويد"** يبدأ التحميل المباشر (سواء من الرابط الخارجي المعتمد أو من الحزمة المرفوعة) مع مؤشر حالة واضح.
       - زر مساند **"تثبيت فوري مباشر على الهاتف (PWA)"** يعمل تلقائياً لمن يفضل التثبيت اللحظي من المتصفح.
       - قسم خاص لمستخدمي **iPhone & iPad** يوضح خطوات الإضافة للشاشة الرئيسية أو الانتقال لمتجر التطبيقات.
  2. **تدفق المالك (Owner / Admin Flow)**:
     - يظهر للمالك زر **"إعدادات ملف APK والروابط (للمالك)"** داخل نافذة التحميل وفي لوحة المشرف.
     - يمكن للمالك الاختيار بين:
       - **رابط خارجي مباشر**: لصق رابط APK (مع محول ذكي يحول رابط Google Drive العادي تلقائياً إلى رابط تنزيل مباشر).
       - **رفع ملف APK من الجهاز**: اختيار ملف `.apk` ليتم رفعه وحفظه في الخادم مع فحص توقيع بداية الملف (`PK` ZIP/APK header) للتأكد من أنه حزمة أندرويد حقيقية وكاملة.
     - عند الحفظ، تتحدث بيانات التحميل فوراً لجميع زوار المنصة.

- **Visual Identity & Theme**:
  - **Aesthetic Direction**: تصميم نظيف وعملي متوافق مع الهوية البصرية لمنصة تيديكلت AI ويدعم الوضعين النهاري والليلي.
  - **Color Palette & Mood**: استخدام متغيرات الهوية الأساسية (`--bg`، `--card`، `--ink`، `--green: #176b52`، `--line`) مع أزرار لمس مريحة (`min-h-[48px]`).
  - **Typography & Hierarchy**: خط عربي واضح للبطاقات والأزرار مع أرقام `tabular-nums` لعرض حجم الملف ورقم الإصدار ونسبة التحميل.

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: الجمع بين الرابط الخارجي المباشر والرفع المحلي مع تحويل روابط Google Drive**
  - *Chosen Approach*: تمكين المالك من وضع رابط خارجي (GitHub / Google Drive / خادم خارجي) أو رفع ملف `.apk` مباشرة إلى الخادم، مع إضافة محول تلقائي لروابط Google Drive (`https://drive.google.com/uc?export=download&id=...`).
  - *Why*: يمنح المالك حرية كاملة؛ فإذا كان الملف كبيراً ومرفوعاً على Google Drive أو GitHub يعمل فوراً، وإذا أراد رفعه مباشرة من هاتفه أو حاسوبه عبر لوحة التحكم يُحفظ على الخادم ويُخدّم بترويسات `application/vnd.android.package-archive` الصحيحة.
- **Decision 2: استثناء مسارات التحميل من Service Worker (`sw.js`) وتوفير بث ثنائي كامل (`Stream + Content-Length`)**
  - *Chosen Approach*: تعديل Service Worker ليتجاهل أي طلب يبدأ بـ `/downloads/` أو `/api/apk/`، وتقديم الملف عبر مسار خادم يضبط `Content-Length` و `Accept-Ranges: bytes` و `Cache-Control: no-store`.
  - *Why*: يمنع انقطاع التحميل في متصفحات أندرويد (Chrome / Samsung Internet) ويمنع تخزين نسخة مقطوعة في الكاش.

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Architecture & Component Diagram**:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    نافذة تحميل التطبيق (DownloadAppModal)               │
│  ┌───────────────────────────────────┐ ┌─────────────────────────────┐  │
│  │       واجهة الزائر (User UI)      │ │  لوحة المالك (Owner Panel)  │  │
│  │ • زر تنزيل APK المباشر            │ │ • إدخال رابط APK خارجي      │  │
│  │ • معلومات الإصدار والحجم الفعلي   │ │ • محول روابط Google Drive   │  │
│  │ • شريط تقدم التحميل وفحص الحزمة   │ │ • رفع ملف .apk مباشر للخادم │  │
│  │ • زر التثبيت الفوري (PWA)         │ │ • تحديث رقم الإصدار والحجم  │  │
│  └─────────────────┬─────────────────┘ └──────────────┬──────────────┘  │
└────────────────────┼──────────────────────────────────┼─────────────────┘
                     │ GET /api/apk/info                │ POST /api/apk/config
                     │ GET /api/apk/download            │ POST /api/apk/upload
                     ▼                                  ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                    خادم تيديكلت (Express Server & Storage)              │
│  • حفظ إعدادات الرابط والإصدار في قاعدة بيانات الإعدادات الدائمة        │
│  • فحص سلامة ترويسة حزمة APK (ZIP/APK Magic Bytes PK\x03\x04)           │
│  • بث الملف مع Content-Length و Accept-Ranges أو التوجيه للرابط الخارجي │
└─────────────────────────────────────────────────────────────────────────┘
```

- **Data Model & State**:
  - `ApkReleaseConfig`:
    - `mode`: `'external_url' | 'uploaded_file'`
    - `externalUrl`: الرابط الخارجي المباشر لملف الـ APK
    - `version`: رقم الإصدار (مثال: `2.4.0`)
    - `fileSizeLabel`: حجم الملف المعروض (مثال: `28.5 MB`)
    - `fileName`: اسم ملف التنزيل (`tidikelt-ai-release.apk`)
    - `releaseNotes`: ملاحظات الإصدار للمستخدمين
    - `updatedAt`: طابع زمني لآخر تحديث
    - `hasValidUploadedApk`: مؤشر يوضح ما إذا كان هناك ملف APK صالح مرفوع على الخادم

- **Interactive Component & State Mapping**:
  - **عند فتح نافذة التحميل**: يجلب المكون أحدث إعدادات `GET /api/apk/info` لعرض الإصدار، الحجم، ونوع الرابط المعتمد.
  - **عند ضغط المستخدم على "تنزيل APK لأندرويد"**:
    - إذا كان المالك قد ضبط رابطاً خارجياً مباشراً، يتم فتح/تنزيل الرابط المباشر فوراً بشكل متوافق مع متصفحات الهواتف والأندرويد.
    - إذا كان المالك قد رفع ملف `.apk` على الخادم، يتم تنزيله عبر `/api/apk/download` مع تتبع نسبة التنزيل (`ReadableStream` / `Content-Length`) والتأكد من اكتماله 100%.
    - إذا لم يقم المالك بعد برفع ملف أو وضع رابط خارجي، يظهر تنبيه واضح للمستخدم مع خيار التثبيت الفوري كتطبيق هاتف عبر المتصفح (PWA) وزر سريع للمالك لإضافة الرابط فوراً.
  - **عند فتح المالك لإعدادات الـ APK**: يمكنه التبديل بين وضع "رابط خارجي مباشر" أو "رفع ملف APK من الجهاز"، وعند الحفظ يتم إرسال الإعدادات إلى الخادم وتحديث الحالة مباشرة.
